# Tarot App

A personal tarot companion for macOS. Lives in the menu bar primarily.

---

## Modes

| Shortcut | Mode |
|---|---|
| `⌘1` | **Search Cards** — floating search bar, look up any card |
| `⌘2` | **Journal** — browse and manage your readings |
| `⌘3` | **Immersive** — fullscreen canvas for laying out spreads |

Press `Esc` to dismiss whichever mode is open.  
`Tab` switches between Search Cards and Journal while the panel is open.

---

## Search Cards (⌘1)

Type any card name to find it. Numbers work too — typing `2` finds Two of Wands, etc.

Click a result to open the card detail popup.

---

## Card Detail

- `R` — reverse / upright the card
- `Esc` — close the popup

---

## Journal (⌘2)

Readings are organised into folders. Right-click a folder or entry for options (rename, delete, move, etc.).

Inside an entry:
- `⌘S` — save
- `Esc` — close without saving

---

## Immersive Mode (⌘3)

The whole screen is a canvas.

| Key / Action | What it does |
|---|---|
| `Space` | Open card search |
| `Esc` | Dismiss search → exit immersive (in order) |
| Click a search result | Place card on canvas |
| Drag a card | Move it around |
| Click a card | Open its detail |
| **Add spread to journal** button | Save all canvas cards as a new journal entry |

Canvas resets to blank each time you enter immersive mode. Max 12 cards.

When saving a spread you'll pick which folder to save it to — or create a new one inline.
